# Адаптивная страница с модальным окном

## Описание проекта

Этот мини-проект реализует **адаптивную веб-страницу** с интерактивным модальным окном.
Дизайн выдержан в **чистом и минималистичном стиле**, с использованием приятной цветовой палитры:

* основной синий `#4a90e2`,
* акцентный оранжевый `#f8a10b`,
* светлый фон и мягкие тени для карточек.

Проект разработан с акцентом на **юзабилити**, **адаптивность** и **легкость восприятия интерфейса**.

---

## Основные элементы

* **Header** — шапка сайта с заголовком и навигацией.
* **Hero-секция** — главный блок с приветствием и кнопкой для открытия модального окна.
* **Feature-карточки** — три адаптивные карточки с описанием преимуществ.
* **Footer** — нижняя часть страницы с копирайтом и контактами.
* **Модальное окно** — появляется при нажатии на кнопку, содержит текст и кнопку закрытия.

---

## Адаптивность

Стили оптимизированы под:

* **≥ 1024px** — десктопная версия;
* **768–1023px** — планшетная версия;
* **≤ 480px** — мобильная версия (верстка перестраивается в колонку, уменьшается текст и отступы).

---

## Используемые технологии

* **HTML5** — структура страницы.
* **CSS3 (Flexbox + Media Queries)** — стилизация и адаптивная верстка.
* **Vanilla JavaScript** — логика модального окна (открытие/закрытие с анимацией).

---

## Функциональность

* При клике на кнопку **«Открыть окно»** — появляется модальное окно.
* Нажатие на фон или кнопку **«Закрыть»** — плавно закрывает окно.
* Реализована **анимация появления и исчезновения**, затемнение фона и фиксированное позиционирование.
